# 기술 설명

## 디스크 구성
- ISO9660 + UDF(NSR02). 게임 데이터는 `DATA/GG.DAT`(약 227MB), 스트리밍 번들 `DATA/STREAM/DATA.RBB`(약 166MB), 실행 파일 `SLPM_661.32`.
- 파일은 이름으로 열기 때문에 위치·크기를 바꾸면 ISO9660 레코드와 UDF File Entry 를 함께 고친다(`tools/isoio.py`, `tools/udf.py`). v1.0 은 모든 파일이 원래 자리에 들어가 ISO 크기가 같다.

## GG.DAT
- `u32 개수` + `u32 오프셋 × 개수`(16바이트 단위, 없는 항목 0xFFFFFFFF). 0번 항목은 32바이트 이름표(`DATA/xxx.CSB` 등), i 번째 이름 = 항목 i+1.
- 크기는 다음 오프셋과의 차로 정해지므로, 크기가 바뀌면 원래 순서대로 다시 쌓고 오프셋 표를 고친다(`build.py: arc_rebuild`).

## DATA.RBB
- `siff` 헤더, 0x80 `RIDX`(u32 바이트 수 + `(오프셋, 크기)` × 842), 데이터 시작 0x3000. 각 `.dat` 번들은 GG.DAT 와 같은 형식.
- 번들 안에 CSB·ARY·글꼴의 사본이 따로 들어 있어 이것도 모두 고친다(`tools/rbb.py`). 번들 크기가 바뀌면 RIDX 와 `DATA/RBBINDEX.TXT`(GG.DAT 안 사본 포함)의 크기를 갱신한다.

## 텍스트
- **CSB**: `csb\0izawa` 헤더, 행·열 수, 셀 폭(16~160바이트) 고정 표, 행/열 이름표. 열 이름으로 표시용 열만 골라(`tools/textcols.py`) 셀 안에서 교체한다.
- **ARY**: CSB 를 컴파일한 표. 헤더(행 구조 크기, 행 수, 필드 수) + 필드(타입 u8, 오프셋 u16; 0=int 1=float 2=u8 3=문자열 5=float×4 7=배열) + 배열 설명자(구조 영역, 재귀) + 값 영역(문자열은 NUL 종료 가변 길이). 길이 정보가 없으므로 값을 다시 직렬화한다(`tools/ary.py`). 게임은 표시용 표를 대부분 ARY 로 읽는다.
- **ELF**: 표시용 문자열 295개를 원래 자리(뒤 패딩 포함 범위)에 덮어쓴다.
- 언어 설정(`_j`/`_e` 접미사) 중 일본어 모드(`_J`) 파일만 바꾼다.

## 인코딩·글꼴
- 게임은 Shift-JIS 문자열을 유니코드로 바꿔 글꼴 표를 찾는다. 한글 802자를 FNT 에 글리프가 있는 제1/2수준 한자 코드에 순서대로 대응시키고, 그 한자 칸에 한글을 그린다(코드 수정 없음).
- **FNT**: `u8 버전, u8, u16 페이지 수` + 페이지마다 `u16 (상위바이트<<8)` + 256 × 8바이트 레코드(하위바이트 인덱스). 레코드: 필드0 하위 12비트 = x, 필드2 하위 12비트 = y, 필드3 상위 바이트 = 텍스처 번호.
- **QTX**(MFZQ): 0x180 에 폭·높이, 0x200 부터 픽셀. 4bpp/8bpp 를 **CT32 폭 64** 로 올린 GS 스위즐 배치(`tools/swz.py`, `tools/qtx.py`), 데이터 끝 +0x80 에 팔레트.
- 작은 글꼴 GGFONT0/1(1024×1024 / 1024×512, 17px 칸): 값 15 본체 + 값 1 우하단 그림자. 15px 로 그린다.
- 큰 글꼴 LARGE.FNT + LARGE0.QTX(23px 칸, 데모·엔딩용): 쓰는 한자만 담은 부분 글꼴이라, 원래 한자 칸을 재활용해 한글을 그리고 대응 코드의 레코드를 새로 지정한다. 20px 안티앨리어싱, 팔레트 5~15 회색 + 2 그림자 + 1 외곽선.

## 와이드 패치
- PCSX2 내장 원본판 패치(CRC DDF29822)의 두 줄을 한글판 CRC(v1.0.5: B4A266D4)용으로 옮겼다. 빌드마다 CRC 가 바뀔 수 있으므로 파일 이름을 다시 확인한다. CRC 는 ELF 전체 32비트 워드 XOR.

## 이름 입력
- `NAMEENTRY_WORD`(CSB·ARY): 18행×20열 문자 표, 앞 10열 영숫자·뒤 10열 가나(0~8행 표시, 9~17행 같은 값). 가나 열을 한글 음절 90칸(가나다순)으로 바꾼다.
- `NAMEENTRY_DEFAULT`: 기본 이름 77개를 표 좌표 `(표, 열, 행)` 목록으로 저장(CSB 는 문자열 "1 x y", ARY 는 float×4, 끝 표시 `(2,0,0)`). 한글 표기 좌표로 다시 쓴다(`tools/names.py`).
- 한글 음절이 늘면 한자 코드 대응이 바뀌어 실행 파일 CRC 가 달라질 수 있으므로 빌드마다 와이드 패치 파일 이름(CRC)을 다시 확인한다.

## 영어 표시 문자열
- 일본어 모드에서도 일부 표(OBJ 아이템 이름, SALVO_TABLE, OBJ_FRG, PANEL_PASSIVE_J·PANEL_A_LEVEL_J 패널 이름, KUNREN_INFO, OPTION_KANRI_J, KGMENU_LAYOUT)는 영어 값을 그대로 보여 준다. 지정한 열(CSB)·파일(ARY)의 영어 값만 번역표(`work/en_ko.tsv`)로 바꾼다(`textcols.EN_CSB`, `EN_ARY`). 모델 ID 같은 소문자 식별자는 번역표에 없으므로 바뀌지 않는다.

## 그림 글자
- `tools/imgtex.py`(QTX RGBA 디코드/인코드, 원본 왕복 일치 확인), `tools/imgpatch.py`(글자 지우기: 투명/인페인팅 → 한글 그리기 → 팔레트 재양자화), `tools/imgspecs.py`(텍스처별 좌표·문구). GG.DAT 와 DATA.RBB 안의 사본 모두 같은 결과로 교체.
